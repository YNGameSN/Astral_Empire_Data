Cómo leer documentos:

Entre corchetes [ ]: elementos obligatorios.

Entre paréntesis ( ): elementos opcionales.

Palabras directas: elementos fijos que nunca cambian.

UAA = Unidad Aliada Activa
UEA = Unidad Enemiga Activa
UED = Unidad Enemiga Derrotada
UAD = Unidad Aliada Derrotada
EAA = Estructura Aliada Activa
EAD = Estructura Aliada Destruida
EAN = Efecto Atribuido o Nativo

Formularios: Otorgan información técnica para la creación de cartas, una versión final del formulario con datos muy tomados en cuenta para el motor.

Las condiciones en efectos que no estén registrados como de combate / afinidad / ambiental / etc se dan con la siguiente nomenclatura:
(efecto) | Sí y solo sí: (condición específica Taxonómica - Momentánea)
o :
(efecto) | Si se da en X% de probabilidad.
o :
(efecto) | Únicamente si se cumple (condición específica Taxonómica - Momentánea) se podrá en X% de probabilidad.
Además se puede usar Mientras y Hasta, para definir tiempo o condición.

Para modificaciones auto aplicadas no se usa la conjugación Nombre | Valores | Objetivo (Taxonomía/Subrasgo/Tamaño técnicos), es reemplazada con:
Atributo (a cambiar) | Efecto (a aplicar / si es necesario) | (+ / -) | Valor 

Para modificaciones de atributos propios o ajenos, usar:
Atributo (a cambiar) | (+ / -) | Valor 

Todos, la forma base y derivados, pueden o no llevar condición.

Para los ataques desbloqueables es opcional colocar como primer dato antes del nombre, qué condiciones se necesita para el desbloqueo.
